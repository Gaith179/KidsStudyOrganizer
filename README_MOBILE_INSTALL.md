## 📱 Quick 1-Tap Installation on Mobile (التثبيت السريع بلمسة واحدة)

Your Kids Study Organizer is engineered as a **Full-Screen Native Progressive Web App (PWA)**, designed specifically for **Android** and **iOS (iPhone)** smartphones.

### 🌐 Method 1: Instant Install via Cloudflare Public Link (No Wi-Fi restrictions)
You can open this secure link directly from any mobile (Father, Mother, Ryan, Jad) anywhere, even on mobile data (4G/5G):
```
https://pork-tan-cancer-level.trycloudflare.com
```

### 🏠 Method 2: Direct Install via Local Wi-Fi
1. Ensure your PC running the server and the mobiles (Father, Mother, Ryan, Jad) are connected to the same home Wi-Fi.
2. On any mobile phone, open the browser (Chrome on Android, or Safari on iPhone) and go to:
   ```
   http://192.168.8.2:8080
   ```
   *(Or scan the QR code located in `mobile_qr.png` or open `http://localhost:8080/mobile_install.html` on your PC).*
3. **On Android**:
   - A banner will appear at the bottom: **"Add StudyHub to Home screen"** or **"Install App"**.
   - Tap **Install**.
   - An official app icon 📚 will appear on your phone's home screen alongside WhatsApp and YouTube.
   - When opened, it runs in **full-screen mode** with no browser bars!
4. **On iPhone (iOS)**:
   - Tap the **Share** button (the square with an arrow pointing up at the bottom).
   - Scroll down and tap **"Add to Home Screen" (إضافة إلى الصفحة الرئيسية)**.
   - Tap **Add**.
   - It will install as an independent iOS app with its own launch icon.
